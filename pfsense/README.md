# pfSense Firewall

**Plan:** Build a functional firewall/gateway and write rules to control the traffic

## Steps
1. Installed pfSense in VirtualBox with two network adapters (WAN and LAN).
2. Configured a static IP on the LAN interface and enabled DHCP for client VMs.
3. Set up the sensor VM to reach the pfSense web interface over HTTPS.
4. Wrote and tested firewall rules (e.g., blocking specific ports/protocols, allowing only necessary traffic).
5. Verified rule behavior by testing connections from the sensor VM.

## Skills Demonstrated
- Network segmentation
- Firewall rule writing
- DHCP / static IP configuration
- VM networking
