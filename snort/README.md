# Snort Intrusion Detection

**Goal:** Detect suspicious or malicious traffic in real time using Snort as an IDS.

## Steps
1. Installed and configured Snort on the Sensor VM.
2. Wrote custom detection rules.
3. Generated test traffic and confirmed Snort logged the detection.
